# 人人登录检测与原生同步浮层设计

**状态：** 方案 1 已确认并实施

**日期：** 2026-08-26

## 目标

本次只解决两个问题：

1. 已登录“人人都是产品经理”时，扩展必须正确显示“已登录”。
2. 将脱离 OpenGZH 风格的居中模态框改成工具栏原生同步浮层，降低遮挡并提升状态判断与操作效率。

四平台协议、串行任务、文章快照、图片上传、草稿保存和权限边界保持不变。不自动发布，不新增扩展权限或运行时依赖。

## 人人登录检测

人人当前写作页把认证信息放在顶层 `var PURE = {...}`，旧版使用 `window.settings = {...}`。解析器同时识别这两种结构，但仍只读取顶层可执行脚本中的对象字面量，不执行页面脚本。

当前结构必须同时满足：

- `PURE.is_user_logged_in` 明确为登录态；
- `PURE.user_id` 与 `userSettings.uid` 一致；
- `PURE.jltoken` 合法且唯一；
- 固定资料接口返回成功，且资料 UID 与页面 UID 一致。

明确未登录时返回 `{ authenticated: false }`。字段残缺、UID 冲突、重复认证对象、非法 token 或页面结构无法严格解析时继续失败关闭。token 只在适配器实例内存中短暂使用，不进入 UI、日志、存储、错误或测试快照。

## 交互模型

同步入口下方打开宽度约 420px 的非模态浮层：

- 不显示全屏遮罩，不模糊或压暗编辑页面；
- 根据工具栏入口的真实位置固定到视口内，桌面右对齐入口，390px 视口保留 8px 安全边距；
- 标题为“同步草稿”，同一行显示“已选 N”和关闭按钮；
- 平台以连续列表和细分隔线呈现，不再使用四张独立卡片；
- 底部说明为“仅保存草稿，不会发布”，唯一主操作为“保存草稿”。

平台操作按状态派生：

- 检测中、处理中、未选择：不显示行操作；
- 已登录：只显示安静的成功状态；
- 需要登录：显示“去登录”“重新检测”和“登录后自动更新”；
- 失败：只显示“重新检测”，不伪装成未登录；
- 保存成功：显示“打开草稿”；
- 未知：提示人工检查草稿箱，不允许盲目重试。

点击“去登录”后，新标签页登录；用户返回 OpenGZH 页面时，扩展自动重检该平台。浮层支持关闭按钮、Escape 和点击浮层外部关闭；关闭按钮与 Escape 把焦点还给同步入口，外部点击不抢走用户正在点击的目标焦点。

## 视觉系统

浮层直接复用 OpenGZH 的暖色设计 token：

- 表面：`#FFFDF8`；次级表面：`#F7F1E8`；强调表面：`#EFE6DB`；
- 正文：`#332821`；次级文字：`#6F5E52`；
- 边框：`#D8C8B8`；强调边框：`#BDA896`；
- 主色：`#B64B39`；hover：`#A94333`；
- 面板圆角 14px，按钮圆角 7–8px，仅保留一层暖色阴影。

平台行高约 62px，图标、名称、状态和上下文操作保持单一阅读轴。状态色只辅助文字，不单独承担语义。动效限制在 160ms 的颜色、背景和轻微位移；`prefers-reduced-motion` 下全部移除。

## 响应式与可访问性

- 面板宽度为 `min(420px, 100vw - 16px)`，最大高度受当前视口和锚点位置约束；
- 390px 下触控操作至少 44px，高度和边距压缩但不隐藏关键信息；
- 保留 `role="dialog"`、标题/说明关联和状态 `aria-live="polite"`；
- 由于是非模态浮层，移除 `aria-modal="true"`；
- 锚点维护 `aria-haspopup`、`aria-controls` 和 `aria-expanded`；
- Tab/Shift+Tab 保留既有浮层内循环，Escape 关闭并恢复焦点；
- 所有按钮、链接、复选框具备 hover、active、disabled 与 `:focus-visible` 状态。

## 改动范围

- `extension/src/adapters/woshipm.js`：兼容当前 `PURE` 登录结构并严格校验身份一致性。
- `extension/tests/adapters/woshipm.test.js`：覆盖当前登录、明确未登录、冲突与伪造结构。
- `extension/src/content/open-gzh.js`：实现非模态锚点浮层、暖色视觉、选中计数和登录返回自动重检。
- `extension/tests/content-script.test.js`：锁定结构、状态操作、定位、焦点、外部关闭和响应式契约。

## 验收标准

1. 人人当前登录结构经资料接口交叉校验后显示“已登录”，旧结构继续兼容。
2. 同步界面不遮挡页面，视觉 token、圆角、边框和主操作与 OpenGZH 一致。
3. 已登录平台不显示无效按钮；需登录平台提供明确操作与返回自动重检。
4. 桌面与 390px 视口无横向溢出，浮层始终位于视口安全区。
5. Escape、外部点击、焦点恢复、状态播报和 44px 移动触控目标符合契约。
6. 不新增权限、依赖、凭据持久化或自动发布行为。
7. 自动化、构建和真实 Chrome 视觉对比全部通过后才可完成交付。
