# 小红书横滑审稿与纵览切换设计

**日期：** 2026-08-19

**状态：** 已确认，直接实施

**范围：** OpenGZH 小红书图片模式的预览方式、当前页导航、性能和浏览器验收

## 1. 背景与目标

当前图片模式把所有 3:4 卡片纵向堆叠。这便于全局检查，但不符合小红书发布后的逐张滑动阅读方式，单张审稿时也容易被上下页干扰。

本次目标是：

- 图片模式默认使用“单卡聚焦 + 前后露边”的横滑审稿。
- 用户可随时切换到纵向总览，两种视图保持同一当前页。
- 复用现有卡片 DOM、媒体注入和 PNG/ZIP 导出链路，不引入第二套渲染或轮播依赖。
- 使用平台原生横向滚动与 CSS Scroll Snap，不使用 3D、模糊、自动播放、循环轮播或逐帧动画。

## 2. 已确认的交互

### 2.1 视图切换

- 图片模式工具栏新增“横滑 / 纵览”分段控件，默认选中横滑。
- 视图模式只属于当前会话 UI 状态，不写入 Markdown、文档 `xhs` 设置或 IndexedDB。
- 切换视图时保留当前页；新视图就绪后使该页进入可见位置。

### 2.2 横滑审稿

- 中央完整显示一张 3:4 卡片，容器宽度允许时露出前后页边缘；窄视口仍保证当前卡片可读。
- 滑动停止后吸附到最近卡片，并更新当前页。
- 支持触摸屏、触控板横向滑动、上一张/下一张按钮，以及预览轨道聚焦后的左右方向键。
- 不将鼠标纵向滚轮映射为翻页，不影响编辑页的正常纵向滚动。
- 首页的“上一张”和尾页的“下一张”禁用，不循环。
- 当前页保留单页下载；正文页保留“页前分页 / 删除手动分页”操作。

### 2.3 纵向总览

- 保留现有纵向卡片堆叠、页间手动分页控件和单页下载。
- 纵览用于检查全局节奏和所有页面，不另建缩略图或影片带。

## 3. 架构与数据流

### 3.1 状态

`main.js` 新增会话级 `xhsPreviewMode`，只允许 `horizontal` 和 `vertical`。`xhsSelectedPageId` 继续是两种视图共享的当前页真源。

当文章重新分页时：

1. 分页前记录当前页 ID 和索引。
2. 新页列表中优先匹配原 ID。
3. ID 已消失时使用原索引，并夹在新页列表边界内。
4. 列表为空时清空当前页。

### 3.2 预览工作区

- 状态、问题和空态位于卡片轨道外层，不参与横向排列。
- 卡片轨道仍使用 `.xhs-image-stack`，避免改变媒体注入和导出查询的边界。
- 横滑模式使用 `display:flex`、`overflow-x:auto` 和 `scroll-snap-type:x mandatory`；纵览模式保持纵向 flex。
- 所有卡片仍只渲染一次。不做虚拟化，避免离屏卡片从 DOM 移除后造成整组导出缺页，也不建立隐藏的导出副本。

### 3.3 选页与缩放

- 上一张/下一张、方向键和页码按钮统一调用选页函数，由该函数更新 ID 并滚动到目标卡片。
- 横滑停止后，使用容器中心与各卡片中心的距离选择最近卡片；滚动处理做小幅延迟合并，不建立逐帧动画循环。
- 缩放继续基于容器宽度。横滑为相邻页预留空间，纵览沿用现有宽度计算；缩放不得大于 1，也不影响 540×720 逻辑卡片和 1080×1440 导出。

## 4. 性能与错误处理

- 视图切换只修改 CSS 布局状态和滚动位置，不触发 Markdown 重解析、重新分页或卡片重渲染。
- 横向滚动由浏览器处理，JavaScript 只在滚动稳定后同步一次当前页。
- 页面重排后目标页不存在时使用夹取后的原索引，不抛出 UI 错误。
- 无卡片时禁用导航和导出操作。原有分页、媒体、字体和 CORS 错误仍由现有问题列表与导出校验处理。
- 切换回文本模式时清理滚动同步定时器和 `ResizeObserver`。

## 5. 可访问性

- 视图切换使用带明确名称的按钮组，通过 `aria-pressed` 暴露当前状态。
- 横滑轨道可获得键盘焦点，卡片暴露“第 N 张，共 M 张”。
- 导航按钮在首尾页使用真实 `disabled`，不仅改变样式。
- 当用户启用减少动效时，程序化翻页使用即时滚动。
- 按钮、输入框和链接获得焦点时，轨道不抢占方向键。

## 6. 测试与验收

### 6.1 自动化测试

- 未知视图值归一化为默认横滑。
- 重新分页后优先保留同 ID；ID 消失时夹取原索引。
- 上一张/下一张在边界不越界。
- HTML 包含可访问的横滑/纵览切换、可聚焦轨道和真实的首尾页禁用按钮。
- CSS 的横滑状态包含横向 overflow 与强制吸附；纵览保持纵向布局。
- 视图切换不调用分页调度，不修改文档设置。

### 6.2 浏览器验收

- 进入图片模式默认横滑，中央完整卡片旁可见相邻页边缘。
- 触控板/触屏滑动停止后吸附到一页，页码与卡片一致。
- 按钮和方向键能逐页导航，首尾不循环；纵向滚轮不会意外翻页。
- 在中间页切换横滑/纵览，两次切换均保持该页。
- 修改 Markdown 导致页数增减后，当前页按 ID 或夹取索引继续。
- 横滑和纵览下单页 PNG 与全部 ZIP 均可导出，输出仍为 1080×1440。
- 360–390px 宽视口中当前卡片不溢出，切换、导航和下载按钮可用。

## 7. 明确不做

- 不引入 3D 翻转、缩放模糊、自动播放、循环轮播或影片带。
- 不做卡片虚拟化或隐藏导出 DOM。
- 不持久化横滑/纵览偏好，不提升文档数据版本。
- 不改变小红书分页、主题、图片、验证和导出契约。
- 不重构与本次预览直接无关的编辑器或样式覆盖功能。

## 8. 发布与回滚

- 本次只新增会话级视图状态和预览布局，不使用数据迁移。
- 若横滑交互在目标浏览器出现问题，可回滚本次视图状态、模板和 CSS，现有纵向卡片与导出链路不需要回滚。
