# 封面排版修复与六套新模板设计

## 背景

OpenGZH 当前提供 40 套公众号封面模板。现有 10 套新模板会根据文字区域宽度自动换行，但其余 30 套仍将完整标题放在固定坐标中；使用 20–30 个中文字符的真实标题时，这 30 套都会水平越过画布。副标题普遍使用固定纵坐标，也会在标题换行后与标题重叠。

部分封面还依赖 `№` 等字体覆盖不稳定的特殊字形，字体选项缺少统一的中文系统回退。PNG 导出链路在字体尚未就绪时即可序列化 SVG，这三点共同构成缺字、方框字或预览/导出字体不一致的风险。

## 目标

- 修复全部现有模板在真实长度中文标题、副标题下的越界和重叠。
- 消除已知的不稳定特殊字形，并为封面字体提供可靠中文回退。
- 新增 6 套构图有明显区分度的封面模板，总数由 40 增至 46。
- 保留现有模板 ID、保存状态、拖拽偏移、撤销/重做和插画图层行为。

## 非目标

- 不重写封面编辑器或模板数据模型。
- 不新增依赖，不引入远程图片或新的字体服务。
- 不自动缩小用户字号，也不覆盖用户手动设置的文字偏移。
- 不改变现有模板的配色、装饰或名称。

## 方案选择

采用“共享文字布局计算 + 模板声明安全区域”的方案。复用现有 `wrapText`、`textW` 和 `lineHeightPx` 能力，提取一个只计算标题换行、副标题起始位置的轻量辅助函数。每套模板继续拥有自己的 SVG，仅传入标题宽度、副标题宽度、标题基线和标题/副标题间距。

不采用逐模板坐标补丁，因为它无法防止下一次长文案回归；也不重做模板系统，因为会扩大保存状态和交互兼容风险。

## 排版行为

每套模板定义一个与构图一致的文字安全区域：全宽模板通常使用左右各 80–110 像素留白，图文分栏模板只使用文字栏宽度。标题按当前字号进行 CJK 感知换行，保留用户显式换行；英文优先在空格处换行。副标题按自己的字号和安全宽度换行，并从标题最后一行之后的固定视觉间距开始。

模板仍通过 `renderTextLines` 输出带 `data-field` 的独立 SVG `<text>` 行，因此当前行内编辑、拖拽和字段偏移逻辑保持不变。

## 字体与乱码处理

- 将装饰性的 `№` 替换为 ASCII `NO.`，避免字体缺少该字符时出现方框。
- 所有可选字体值追加 `PingFang SC`、`Microsoft YaHei` 和通用 `sans-serif` 或 `serif` 回退。
- PNG 导出在构造 SVG 图片前等待 `document.fonts.ready`，减少页面字体尚未加载完成造成的预览/导出差异。
- 动态文字继续统一经过 XML 转义，新增回归用例覆盖 `& < > "`。

## 六套新增模板

### 专业编辑风

1. **深度社论 `editorial-depth`**：暖白纸张、深墨文字、细分栏线和小面积朱红索引，适合行业分析与观点文章。
2. **数据简报 `data-brief`**：午夜蓝底、青绿色网格与抽象数据轨道，适合数据复盘和研究摘要。
3. **产品发布 `product-launch`**：钴蓝与冷白的大块网格、版本标记和发布窗口，适合产品更新与功能公告。

### 创意视觉风

4. **棱镜光谱 `prism-spectrum`**：深色背景上的半透明光谱棱面，适合 AI、设计和趋势话题。
5. **纸雕窗口 `paper-cut-window`**：多层纸张切口与柔和投影感色块，适合品牌故事和生活方式内容。
6. **像素未来 `pixel-future`**：无特殊字体依赖的像素栅格、模块化光点和高对比标题，适合科技与游戏内容。

新增模板只使用 SVG 原生图形和现有字体，不增加图片资源。每套模板包含 `TEMPLATE_META` 场景说明与至少两个风格标签，并归入现有分类。

## 兼容与失败处理

- 原有 40 个 ID 和顺序保持不变，新模板追加到对应分类末尾。
- `restoreCoverState` 继续对不存在的旧 ID 回退到 `pure-white`。
- 空标题或空副标题不生成多余行；极长文字允许继续向下流动，但测试会确保默认允许字号与约定的真实文案样本处于 1200×510 画布内。
- 字体加载失败时依靠系统中文字体回退，不阻止 PNG 导出。

## 验收

- 模板总数为 46，ID 唯一，元数据双向完整。
- 46 套模板都能生成合法、闭合且使用 `viewBox="0 0 1200 510"` 的 SVG。
- 真实长度中文标题和副标题在各模板文字安全区内换行，所有文字行位于画布内，副标题不与标题重叠。
- 动态文本特殊字符经过转义，输出可被 XML 解析。
- 源码不再包含依赖特定字体的 `№`。
- 浏览器中抽检全部模板缩略图；重点检查 30 套旧模板和 6 套新模板的大图预览。
- PNG 导出抽检系统中文字体和一种网络字体，文字可读且位置与预览一致。
- `npm test` 与 `git diff --check` 通过。

## 回滚

代码改动集中在封面模板、字体选项、PNG 导出与封面测试。若上线后出现异常，可整体回滚该提交；现有保存数据因模板 ID 未变，不需要迁移或清理。
