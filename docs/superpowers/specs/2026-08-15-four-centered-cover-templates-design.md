# 四套居中标签封面设计

## 目标

在现有封面工作台中新增 4 套 `1200 × 510` SVG 封面。四套模板都采用居中标题构图，并在画面内明确展示两个可编辑标签：类型和作者。新用户与“恢复默认”后的默认值为“技术分享”和“AI产品零度”。

## 方案选择

采用 4 个独立模板，而不是改造旧模板的对齐模式，也不引入通用皮肤生成器。独立模板能复用现有模板注册、字段编辑、撤销重做和 PNG 导出链路，同时避免改变已有模板输出。

## 视觉设计

新增“居中布局”分类，包含：

1. `center-midnight-prism` / 午夜棱镜：深蓝底、低对比几何切面，接近参考图的沉稳科技感。
2. `center-editorial-seal` / 编辑印记：暖白纸张、红黑印刷标记，适合方法论和深度文章。
3. `center-circuit-grid` / 电路网格：深青网格、节点与电路线，适合技术分享和架构内容。
4. `center-orbit-glow` / 环形微光：黑紫背景、同心轨道与柔和光晕，适合 AI 和趋势主题。

四套模板共享同一信息层级：顶部居中的“类型 / 值”和“作者 / 值”元信息行，中部居中的主标题，下方居中的副标题。装饰只能占用文字安全区外围，不得穿过主标题与副标题。

## 数据与交互

- 复用 `coverContent.tag` 作为“类型”的值，复用 `coverContent.author` 作为“作者”的值。
- 固定文字“类型”和“作者”只是视觉标签；实际值继续保留 `data-field="tag"` 与 `data-field="author"`，支持现有行内编辑和拖拽逻辑。
- 四套模板都声明 `tag`、`title`、`subtitle`、`author` 可用，不新增字段、不改变本地存储结构。
- 默认作者从 `@OpenGZH` 调整为 `AI产品零度`；已有本地保存内容保持原值，不做迁移。

## 实现边界

- 修改 `assets/scripts/cover/templates.js`：增加共享的居中元信息行渲染函数、4 个模板、元数据和模板注册。
- 修改 `assets/scripts/cover/renderer.js`：为新分类增加“居中布局”显示名。
- 修改 `assets/scripts/main.js`：更新初始值和“恢复默认”的作者值。
- 修改 `assets/scripts/cover/__tests__/templates.test.js`：模板总数变为 44，验证 4 套模板的分类、字段、标签和长文本布局。
- 修改 `README.md` 与应用内说明中的模板数量：40 → 44。
- 不修改 PNG 导出实现、插画系统、现有模板 SVG 和偏好存储键。

## 验收标准

- 模板列表新增“居中布局”分类，恰好包含 4 套新模板。
- 4 套模板均渲染“类型”“作者”固定标签，并把当前类型、作者值作为可编辑字段输出。
- 使用 20–30 个中文字符的标题和副标题时，标题自动换行，副标题始终位于标题下方，所有文字留在 `1200 × 510` 画布内。
- 默认内容显示“技术分享”和“AI产品零度”；已有保存数据不被覆盖。
- 全量 Vitest、SVG XML 校验和 `git diff --check` 通过；实际导出至少覆盖 4 套新模板的 `2400 × 1020` PNG。

## 风险与回滚

- 风险集中在长中文标题导致纵向拥挤，以及元信息行侵入装饰区域。通过统一文字安全区和全量长文本测试约束。
- 回滚只需移除 4 个模板注册、元数据、分类标签、默认作者变更及对应测试/文档，不涉及用户数据迁移。
