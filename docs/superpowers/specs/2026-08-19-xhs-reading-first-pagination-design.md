# 小红书完整文章排版与均衡分页设计

**日期：** 2026-08-19

**状态：** 设计已确认，待转入实施计划

**范围：** OpenGZH 小红书图片模式的字号、正文容量、分页平衡、长文提示与验收标准

## 1. 背景与问题

当前图片模式的核心目标是“忠实保留 Markdown 全文并分页导出”。标准档在 540×720 逻辑画布上使用 24px 正文、1.65 行高和 20px 块间距，而分页器采用局部贪心放置。这组合更适合“大字知识卡”，对完整文章会产生三个问题：

1. 每页文字容量偏低，简短文章也会被拆成较多图片。
2. 当一个完整段落放不进当前页、但能单独放进下一页时，现实现会直接换页，不会先按句子边界利用当前页剩余空间。
3. 图片、代码、表格等大块不能与上一页组合时，会留下明显的半空页，界面又没有解释页数的组成。

本设计把目标改为：**在逐字保留原文、不降低手机可读性的前提下，尽可能降低碎页、提高单页信息完整度，并让长文的页数原因可理解。**

## 2. 已确认的产品契约

- 左侧 Markdown 仍是唯一原文，不自动摘要、删减、改写或改变顺序。
- 第一个 H1 继续由封面承载；首段可用于封面摘要，但正文仍完整保留。
- 图片模式仍为“封面 + 正文分页”，固定 3:4，导出 1080×1440 PNG。
- `<!-- xhs-page -->` 继续是手动分页的唯一真源，均衡分页不得跨越该边界。
- 不使用“每页动态缩字”来填满画布，同一篇文章在同一密度档内保持字号一致。
- 长文不设硬性导出上限；超过 12 张时给出“建议拆成系列”的编辑提示，但仍允许完整导出。
- 12 张是站内编辑建议阈值，不宣称为小红书官方限制，也不替代现有上传能力警告。

## 3. 方案比较

### 方案一：只修改字号与间距

优点是修改范围小、风险低；缺点是当分页边界落在完整段落、列表或媒体块之前时，仍会产生半空页。它只解决容量，不解决分页质量。

### 方案二：统一字号 + 扩大有效正文区 + 有限回溯的均衡分页（采用）

先设置全文统一的可读字号，再在语义边界内调整相邻页分割点。它同时降低页数、孤立标题和明显碎页，且不改变原文。额外复杂度通过“只看相邻页、限制候选数”加以控制。

### 方案三：逐页动态缩字

可以进一步减少页数，但会让相邻卡片的字号和节奏不一致，并诱导系统把长文问题隐藏在更小的字里。不采用。

## 4. 排版规格

### 4.1 三档密度

| 密度 | 正文字号 | 行高 | 块间距 | 用途 |
| --- | ---: | ---: | ---: | --- |
| 舒展 | 22px | 1.65 | 18px | 文字较少、强调轻松阅读 |
| 标准 | 20px | 1.55 | 14px | 默认；完整文章的阅读与容量平衡 |
| 紧凑 | 18px | 1.48 | 10px | 用户主动选择的高密度文章或附录 |

正文字号不得低于 18px。封面字号与正文密度解耦，不随表格变化。代码和表格字号继续守住现有最小可读性校验。

### 4.2 画布与标题

- 卡片仍为 540×720 逻辑像素。
- 正文区左右边距由 44px 收窄为 36px；顶部 48px、底部 64px 保持不变，避免影响页脚和五套主题的安全区。
- H2 保留主题化强化样式，但基础字号随新的正文字号等比收敛。
- H2 、H3 和 H4 的视觉层级由字重、色彩、边框和留白共同建立，不依赖过大字号。
- 五套主题可保留各自装饰，但不得改变同一密度档的正文基础字号。

## 5. 均衡分页设计

### 5.1 语义单元

现有语义解析结果继续使用，但分页时把可分块预处理为更小的候选单元：

- 段落：优先按句子边界切分，原始源码范围和顺序保留。
- 列表：只在列表项之间切分。
- 表格：只在行之间切分，每个续页重复表头。
- 代码：只在代码行之间切分，保留语言标识并延续行号。
- 图片、公式和不可安全拆分的 HTML：保持原子块。

重要变化：段落即使能够完整放入下一页，只要它不能完整放入当前页，分页器仍应评估是否在句子边界切分，先利用当前页的有效空间。

### 5.2 不可违反的约束

- 任何候选页不得水平或垂直溢出。
- 标题不得孤立在页尾，必须与至少一个有效内容单元同页。
- 不得跨越手动分页标记回溯或合并。
- 不得打乱 `sourceStart` 顺序。
- 不得为了填满页面改写文字、隐藏块或调整单页字号。
- 段落被拆分时，如果原段落有多个句子，页尾和续页片段都不应只留一行孤文；以实际 DOM 高度至少两个正文行框作为可视校验。

### 5.3 有限回溯与评分

1. 首先按源顺序生成一份确定性贪心分页结果。
2. 对每个自动分页边界，只枚举相邻两页中语义合法的边界，最多检查 24 个候选，不做全文指数级搜索。
3. 先剔除溢出、孤立标题、跨手动边界和孤行候选。
4. 剩余候选按“总页数更少、两页利用率更均衡、语义拆分更少”的顺序评分。
5. 相同输入、主题、密度和媒体尺寸必须得到相同页序。

分页是有上限的局部启发式调整，不引入通用全局排版求解器。如果候选分析失败，必须回退到通过溢出校验的确定性贪心结果，不得丢失内容。

### 5.4 页面利用率与短文本版式

- 普通正文页的期望使用率为 65%–90%，这是评分偏好，不是为填满而破坏语义的强制规则。
- 原子图片、公式、代码块或表格边界可以导致低利用率，这种页不通过缩字或破坏原子性来“补齐”。
- 最后一页或被原子块迫使低于 55% 的纯文本页，设置运行时 `layoutHint: 'short'`；渲染器采用更突出标题、适度垂直居中的短文本版式，但不改变字号和源文。
- `layoutHint` 只是每次分页派生的页模型字段，不写入 Markdown，也不需要持久化。

## 6. 图片与复杂内容

- 正文图片继续保持完整比例，封面图片才允许按焦点裁剪。
- 图片和相邻的说明文字同页可完整容纳时，优先同页；否则图片移入下一页或独立成页。
- 多图块仍以原顺序拆分，不为降低页数而裁剪、删除或重排图片。
- 表格按行分页并重复表头；代码按行分页并延续语言与行号；公式不在无安全规则时强制拆行。
- 远程媒体、字体等待、CORS 失败和导出阻断语义保持现有契约。

## 7. 界面与反馈

### 7.1 页数摘要

图片模式工具栏在分页完成后显示结构化摘要：

`15 张：封面 1 + 正文 9 + 图片 3 + 代码/表格 2`

分类根据每页主版式计数，各页只计入一个类别，保证各项之和等于总页数。封面始终独立计数。

### 7.2 长文建议

- 总页数大于 12 时，显示：“当前共 N 张，为了更好的滑动阅读体验，建议按章节拆成系列内容。仍可完整导出。”
- 该提示不阻断 ZIP 或单页下载。
- 现有溢出、媒体、字体和 CORS 问题仍按校验器规则阻断相应导出，不与页数建议混用。

### 7.3 分页进度与失败

- 继续在停止输入 450ms 后重新分页。
- 新一轮分页开始时取消或废弃上一轮的过时结果，不让旧结果覆盖新内容。
- 均衡阶段异常时回退到已通过溢出检查的贪心分页，并在开发控制台记录一条有边界的警告；不向普通用户暴露内部算法名称。
- 如果贪心分页也无法容纳不可拆块，继续返回指向具体块的可操作问题，不静默删除。

## 8. 组件边界与数据流

### 8.1 不变的边界

- `semantic-parser.js` 继续负责 Markdown token 到有源码范围的语义块。
- `renderer.js` 继续是实际 DOM 测量与卡片 HTML 渲染的唯一边界。
- `validator.js` 和导出链路继续负责字体、媒体、溢出、对比度与 Canvas 安全性，分页器不复制这些校验。
- 文档级主题、密度、封面、署名和目录配置的持久化结构保持不变。

### 8.2 修改的边界

- `constants.js`：替换三档密度值，新增系列建议阈值；不把 12 写成上传硬上限。
- `paginator.js`：提取可分语义单元，实现候选分割、约束检查、有限回溯和确定性评分。
- `renderer.js`：提供候选页的实际高度/利用率测量，渲染 `layoutHint: 'short'`。
- `xhs.css`：落地字号、行高、块间距、横向安全区和短文本版式。
- `main.js` 与 `index.html`：显示页数组成、12 张系列建议和不阻断导出的文案。

### 8.3 数据流

`Markdown 原文 → 语义块 → 可分候选单元 → DOM 实测贪心分页 → 相邻页有限回溯 → 页模型 + layoutHint → 预览/校验/导出`

完整性校验将最终页模型按 `sourceStart` 还原成语义单元序列，与解析阶段的输入序列比对，确保没有丢失、重复或重排。

## 9. 测试与验收

### 9.1 纯函数和分页单测

- 三档密度归一化后精确等于 22/20/18px 及对应行高和间距。
- 未知密度仍回退到标准档。
- 段落可在当前页句子边界切分，即使完整段落能单独放入下一页。
- 标题不会单独成为页尾，手动标记不会被跨越。
- 列表、表格、代码、图片和公式只在各自允许的边界切分。
- 有限回溯在候选数上限内结束，评分结果不受对象枚举或异步返回顺序影响。
- 回溯失败时返回可渲染的贪心结果，不丢失块。
- 页数摘要各分类之和等于总页数，12 张以下不显示系列建议，13 张起显示但不阻断导出。
- 把最终页内容按源顺序合并后，与解析后原始语义内容逐块相等。

### 9.2 真实 DOM 和浏览器验收

- 274 字、两个小节的无媒体示例，标准档生成 2 张：封面 1 + 正文 1。
- 当前 2428 字默认示例，在图片可正常解析时，标准档总页数不高于 14，且原文完整。
- 五套主题×三档密度均无水平/垂直溢出，正文字号与所选档位一致。
- 没有仅含标题的自动分页页面。
- 纯文本低利用率尾页使用短文本版式，但 DOM 中的文字、源码范围和页序不变。
- ZIP 和单页 PNG 仍为 1080×1440，页码、字体、媒体失败和 CORS 阻断逻辑无回归。
- 主题、密度、封面、署名、目录和手动分页状态刷新后仍正确恢复。

## 11. 发布与回滚

- 保留现有图片模式功能开关作为整体回滚边界。
- 均衡阶段是贪心分页之后的独立纯算法阶段，实施时应保留可单独关闭的局部常量，用于紧急回退到已验证的贪心路径。
- 回滚均衡分页时不回滚新字号和页数说明，除非它们各自的浏览器验收失败。
- 不提升现有文档数据版本；本设计没有新增需要持久化的用户字段。
