# OpenGZH 「深海夜航」全局界面主题设计

**日期：** 2026-08-22

**状态：** 用户已确认 C 方案及应用范围

## 目标

将当前「米白 + 玉绿」的 Ink & Jade 应用外观替换为「深海夜航」深色工作台，覆盖封面图、文本和图片三种工作区。主题只改变编辑器外壳与操作控件，不改变文章、封面和小红书图片的真实输出样式。

成功标准：

- 三种工作区的顶栏、面板、编辑区、工具栏、下拉面板、弹窗和状态反馈形成同一套深色界面。
- 长时间写作时主次层级清楚，小字、图标、选中态和键盘焦点均可辨认。
- 微信文章预览、封面 SVG/PNG 和小红书卡片的渲染与导出内容在主题更换前后保持一致。

## 产品决策

- 「深海夜航」直接成为唯一的默认应用主题。
- 不新增主题切换器、设置项、本地存储字段或 `prefers-color-scheme` 分支。
- 不改变布局、字体、字号、间距、圆角和交互流程；本次只处理颜色、阴影和必要的对比度状态。
- 保留现有文章「深色预览」功能。它是内容预览模式，与应用外壳主题互不替代。

## 颜色系统

| 角色 | 颜色 | 用途 |
| --- | --- | --- |
| 应用背景 | `#0D1420` | 主工作区、预览区外围 |
| 次级背景 | `#111927` | 输入区、工具栏、嵌套区域 |
| 抬升面板 | `#151E2C` | 顶栏、侧栏、下拉面板、弹窗 |
| 悬停/选中底 | `#26365E` | 弱调选中、悬停、标签 |
| 主边框 | `#29364B` | 分隔线、输入框、卡片边框 |
| 强边框 | `#3A4962` | 悬停边框、活动分隔线 |
| 主文字 | `#EDF3FF` | 标题、正文、重要图标 |
| 次文字 | `#B7C3D7` | 常规标签、辅助说明 |
| 弱文字 | `#91A0B7` | 占位符、元数据、禁用前的次级信息 |
| 主强调 | `#7895FF` | 链接、焦点环、选中边框、品牌标识 |
| 强调上文字 | `#09111F` | 亮蓝填充按钮上的文字和图标 |

对比度约束：

- `#EDF3FF` / `#151E2C` 对比度约为 `15.04:1`。
- `#91A0B7` / `#151E2C` 对比度约为 `6.31:1`。
- `#7895FF` / `#0D1420` 对比度约为 `6.63:1`。
- 白字放在 `#7895FF` 上只有约 `2.78:1`，因此填充型蓝色按钮必须使用 `#09111F` 文字，不得沿用当前的纯白按钮文字。

错误、警告和成功颜色继续表达语义，但要在深色面板上重新校验对比度，不把主强调蓝当作语义状态的替代。

## 应用范围

### 需要换色的应用外壳

- 全局顶栏、OpenGZH 标识、封面/文本/图片模式切换。
- Markdown 编辑器背景、工具栏、文件区、拖拽分隔线和选择卡片浮层。
- 文章预览区外围、设备切换、主题/排版下拉面板和复制操作。
- 封面工作区的模板列表、工具栏、内容表单、选中态和面板收起控件。
- 图片模式的工作区、分页导航、封面编辑面板、导出操作和警告提示。
- 通用输入框、按钮、下拉选择、滑杆、复选框、滚动条、弹窗、遮罩、Toast 和底部状态栏。

### 必须保持原样的「输出真相区」

- `renderedContent` 内的微信文章主题、代码块主题、卡片样式、引用和结尾动效。
- 封面预览中的 SVG 画布、文字和装饰元素。
- `.xhs-card` 及其五套图片主题、封面图片和导出 PNG。
- 复制到微信的 HTML、表格 PNG、封面 PNG 与小红书 ZIP/PNG 产物。

应用外壳样式不得通过宽泛选择器或 CSS 变量继承泄漏到这些区域。实现时应优先复用现有的语义变量，只改应用外壳中已确认为浅色假设的硬编码颜色。

## 组件状态

- 默认：抬升面板与次级背景至少由边框或明度差区分。
- 悬停：使用 `#26365E` 底色或 `#3A4962` 边框，不再依赖浅色阴影。
- 选中：强调底色、强调边框或形状标记至少出现两种，不仅靠文字变蓝。
- 键盘焦点：使用可见的 `#7895FF` 外环，不移除原生焦点而不提供替代样式。
- 禁用：同时降低文字与边框对比，并保留形态差异；禁用态不要与未选中态完全相同。
- 高风险操作：删除、错误和警告继续使用语义色和文字/图标提示，不改成品牌蓝。

## 实现边界

预计只修改样式与样式缓存版本：

- `assets/styles/base.css`：替换全局语义颜色、阴影和共享应用外壳状态。
- `assets/styles/editor.css`：收敛编辑器、预览外围、工具栏与卡片选择浮层中的浅色假设。
- `assets/styles/panel.css`：修改主题/排版面板、代码样式选择器、设置面板和弹出层。
- `assets/styles/cover.css`：修改封面工作台外壳和表单控件，不改封面 SVG。
- `assets/styles/xhs.css`：只修改图片模式工作台外壳，不改 `.xhs-card` 内部主题变量。
- `index.html`：仅在 CSS 文件发生变更时更新对应的查询版本，避免部署后浏览器继续使用旧样式。

如果不修改 JavaScript 就能完整覆盖界面，不引入运行时主题层。不新增依赖。

## 验证设计

### 自动化检查

- 增加一个最小的应用主题合同测试，直接读取 `base.css`，断言核心颜色变量与对比度下限。
- 断言填充型强调按钮使用深色 `on-accent` 文字，避免恢复为低对比度白字。
- 运行全量 `npm test`、`git diff --check` 与变更文件的基本语法检查。
- 既有文章主题、代码主题、封面、表格图片和小红书校验测试必须全部通过。

### 真实浏览器检查

- 在桌面宽度下逐一检查封面、文本和图片三个模式，覆盖默认、悬停、选中、焦点、禁用、下拉面板和弹窗。
- 在 `390px` 宽度下检查已有响应式布局，不因深色边框或焦点环产生溢出。
- 使用键盘遍历主要操作，确认焦点始终可见。
- 分别查看普通文章主题、原生深色文章主题、文章深色预览、封面模板和五套小红书主题，确认应用外壳颜色没有泄漏。
- 对比更换前后的 `renderedContent` 与复制/导出产物，内容结构、内联样式和尺寸必须一致。

## 非目标

- 不提供浅色/深色双主题或系统自动跟随。
- 不重设界面布局、品牌 Logo、图标、字体或交互。
- 不改文章主题、代码主题、封面模板、小红书主题或导出协议。
- 不顺手整理与换色无关的 CSS 选择器、命名或重复规则。

## 发布与回滚

这是无数据迁移的 CSS 外观更换。实现提交应只包含主题相关样式、最小合同测试和样式缓存版本。如需回滚，直接回退该实现提交即可；不会遗留无法读取的用户偏好或文档状态。
